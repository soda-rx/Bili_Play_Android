## 常见问题

### 旧版如何迁移到 1.0.0 正式版？

旧版签名私钥已丢失，正式版采用独立安装身份，可以和旧版同时保留。请直接安装正式版，无需先卸载旧版。

在正式版重新登录 B 站即可读取该账号的收藏夹、关注等平台内容。本地播放记录、队列、设置及下载记录不会自动导入。请先保留旧版；已下载音乐可在旧版下载列表中通过“分享文件”转存。后续正式版将保持同一身份与签名，以支持正常覆盖升级。

### 为什么部分内容无法播放？

请优先检查原内容是否失效并稍后再试。若提示“当前资源没有可用的音源”，内容可能受地区或版权限制；正在使用代理软件时，请关闭代理后重新播放。队列中无法播放的歌曲会自动跳过，连续失败会停止重试。

### 为什么有些音乐没有歌词？

Bili Play 的歌词数据来源于原视频提供的字幕（包括 B 站 AI 字幕）。若原视频未提供可用字幕，应用将无法显示对应歌词。

### 为什么没有 Hi-Res 选项？

仅当原视频实际包含 Hi-Res 音源且当前账号拥有相应访问权益时，该选项才会出现。

应用默认按账号权限请求可用的最高音质，不再提供单独的“优先使用 Hi-Res”开关。音质选择会按账号保存在播放页的音质菜单中：选择 Hi-Res 后，遇到只有标准音质的歌曲会暂用标准音质，之后播放支持 Hi-Res 的歌曲时自动恢复；选择标准音质则保持标准音质。

### 如何搜索列表和批量下载？

收藏夹、UP 主个人空间和播放列表顶部均提供搜索按钮，点击后进入当前范围的独立搜索页；搜索页只保留返回、搜索框和框内提示，返回后保留原列表。

收藏夹与 UP 主个人空间右上角提供选择图标。进入选择后可勾选已加载歌曲：收藏夹可批量取消收藏（仅自己的收藏夹）或加入下载任务；UP 主个人空间可批量加入下载任务；“全选”针对当前已加载列表。范围搜索页只保留返回与搜索框；没有匹配内容时不显示额外提示。下载对话框只提供“标准”和“Hi-Res”音质，音频以 MP3 320 kbps 保存，不支持所选音质时使用标准音质。

### 私信可以发送消息吗？

可以。私信会话底部提供输入框，可发送文字、emoji 表情和图片，也可插入 @。图片通过系统照片选择器添加，只有点击“发送”后才会压缩并上传；草稿和待发送图片仅保存在内存中，切换会话或退出后不会持久化。消息发送失败时保留草稿供手动重试，不会自动重发；私信是否可用取决于平台和账号状态。

### 通知中心可以删除通知吗？

可以。在通知上长按即可删除；点赞、回复与 @ 会同步删除服务器上的通知，系统通知暂无云端删除接口，只会在当前账号的设备上隐藏。点击点赞、回复与 @ 通知会直接在应用内打开关联视频，回复与 @ 还会打开该视频的评论。

### 推荐是如何生成的？

主页推荐保持平台音乐频道与指定音乐 UP 的原有来源，并在每次刷新时结合播放历史、已喜欢的创作者做轻量个性化。同一批推荐内部不会重复歌曲、尽量做到一位创作者一首；最近几批展示过的歌曲会优先排除，只有候选不足时才回退补充。

### 评论可以查看和发送图片吗？

评论及回复中的图片可点击查看大图，支持双指缩放、双击和多图切换。输入区的图片按钮可通过系统照片选择器添加最多九张图片，发送前可预览或移除，也可不填写文字直接发送。只有点击发送才会上传；发送时会转换为静态图片、压缩并移除位置等元数据。发送失败会保留当前草稿，图片评论是否可用仍取决于平台和账号权限。点击评论者的头像或昵称可进入其个人空间。

### 如何更新软件？

应用启动时检查本仓库的正式 Release，并在发现新版本时提醒。自动下载默认开启，可在设置中关闭；开启自动下载时“更新提醒”保持开启且不可关闭。下载可能使用移动数据。点击“更新”后由系统显示安装确认，首次使用可能需要允许此应用请求安装。版本、包身份或签名不兼容的安装包不会交给系统安装。设置页的更新检查行会显示当前版本。
