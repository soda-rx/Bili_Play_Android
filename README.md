## 常见问题

### 为什么部分内容无法播放？

请先关闭代理软件，并确认该资源在哔哩哔哩上可以正常播放。部分访问受限的资源，将在后续版本中持续优化解析逻辑。

### 为什么有些音乐没有歌词？

歌词数据来源于原视频提供的字幕（包括 B 站 AI 字幕）。若原视频未提供可用字幕，应用将无法显示歌词。

### 为什么没有 Hi-Res 选项？

仅当原视频实际包含 Hi-Res 音源，该选项才会出现。
