## 常见问题

### 为什么部分内容无法播放？

部分内容因访问受限暂无法播放。此类资源将在后续版本中持续优化解析逻辑，力求满足更多播放需求。

### 为什么有些音乐没有歌词？

Bili Play 的歌词数据来源于原视频提供的字幕（包括 B 站 AI 字幕）。若原视频未提供可用字幕，应用将无法显示对应歌词。

### 为什么没有 Hi-Res 选项？

仅当原视频实际包含 Hi-Res 音源且当前账号拥有相应访问权益时，该选项才会出现。
