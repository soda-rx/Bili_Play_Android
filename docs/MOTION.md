# 界面与动效

- 一级页面使用原生HorizontalPager。按钮移动与目标处回弹使用同一弹簧和同一scroll互斥区，不在完成后追加一次kick；实际手势仍由原生Pager处理，边缘装饰只接收未消费距离。导航固定，胶囊作为页面节点随页移动。
- 二级页面以稳定场景键和导航visit区分新进入、返回和内容更新；每次新进入有展开动画，加载或普通操作不重播卡片动画。主页面共享Pager场景，详情/队列共享播放场景；只有首页原位重选触发回顶/刷新，跨标签保留位置。
- 播放详情、共享封面及底栏升降共用.8/420弹簧。封面起点来自实际图槽，落点扣除整页位移，页面停稳后交接原生图像；歌词退出没有可见大封面，不执行伪缩小。详情退出时导航在背后预组合，视口尺寸不变。
- 每次从播放区外进入详情递增playerSession，媒体Pager只在当前组合中记忆，选中模式与歌曲由ViewModel保存。队列/评论返回保留模式。程序复位不选曲、不回写歌词、不取消hero；真实手势停稳才提交，并验证前台会话及歌曲。分页信号按实例认领，旧页面不得改动新页面。
- 队列有独立Animatable管理附着和位移，重复打开重新进入，中途反向沿当前位移继续，不因数据变化重启。隐藏的播放器移除无障碍语义，队列退出不重播封面与取色。
- 旋转、封面几何和背景颜色仅在绘制阶段读取逐帧值；播放进度时钟只驱动进度条及当前歌词。使用设备当前分辨率最高受支持刷新模式，不等同于实测帧率保证。系统关闭/缩放动画时遵循系统设置。
- 悬浮播放器仅可见表面接收触摸，列表末尾提供滚动避让，不以不可见大矩形挡住页面。Android12起GPU玻璃背景，旧系统使用半透降级。胶囊保留玻璃描边。
- 全窗口背景由封面正方形采样扩展，功能条使用同一渐变底部略深颜色，标题栏/系统栏随场景同步。无歌曲用主题Monet，取色失败用中性灰，不用主题色冒充封面色。
- 歌词提前300ms，焦点约27%高度，长行自适应并留缩放边界。封面/歌词左右切换；首次自动演示一次，真实触摸优先中断。字幕标记只依据来源证据。
- 评论/回复用稳定路由驱动双向转场；表情面板统一280dp并按屏幕夹紧，布局阶段接管IME剩余高度，不随键盘高度增高。选项行透出弹窗背景。

框架约定参考：[PagerState](https://developer.android.com/reference/kotlin/androidx/compose/foundation/pager/PagerState)、[MediaSession系统入口](https://developer.android.com/reference/androidx/media3/session/MediaSession.Builder)、[WebView深浅色](https://developer.android.com/develop/ui/views/layout/webapps/dark-theme)。实际设备的视觉和触摸验收见DEVICE_ACCEPTANCE.md。
