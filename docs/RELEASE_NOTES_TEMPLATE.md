# 更新日志模板

发布标题单独填写：
- Windows：Bili Play v<完整版本>
- Android：Bili Play Android v<完整版本>

复制下面内容后，替换占位文字并删除空分类。逐条对照提交、Issue、PR，使用普通用户能理解的描述。

~~~markdown
## 新增

- 待填写：用户可以使用的新功能。

## 修复

- 待填写：修复在什么情况下出现的具体问题。（由 @贡献者 报告或修复，#PR编号）

## 改进

- 待填写：性能、界面或操作体验上的实际改善。
~~~

没有依据的署名或 PR 引用应删除，同一问题不要跨分类重复。单纯维护发布流程应按实际内容说明，不包装成新应用功能。重要迁移提醒放在分类前的普通段落中。模板含占位文字，不能直接通过发布检查。
